# Homebrew Tap

Official Homebrew Tap for [AgentMicro](https://github.com/fizzy718/AgentMicro).

Install the latest signed and notarized AgentMicro release:

```sh
brew install --cask fizzy718/tap/agentmicro
```

The Cask tracks the current GitHub Release DMG and is updated automatically after
new AgentMicro releases. Once AgentMicro meets
[Homebrew Cask's admission requirements](https://docs.brew.sh/Acceptable-Casks),
it can be submitted upstream; after acceptance, the shorter command will work:

```sh
brew install --cask agentmicro
```

Run `brew upgrade --cask agentmicro` (or the fully qualified Tap name until the
upstream submission is accepted) to update it.
